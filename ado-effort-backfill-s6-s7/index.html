04 How it was written, and why it needed a rule bypass

The blocker: Effort is read-only once a PBI is Done

A plain PATCH was rejected with TF401320: Rule Error for field Effort. Error code: ReadOnly, InvalidNotOldValue. Both targets are already Done, and this process locks Effort on the transition to Done — so the field could not simply be filled in.

I did not reopen them. Reopening would reset ClosedDate and put two bogus state changes into the history of items closed on 2026-10-21 and 2026-10-23. Instead the write used bypassRules=true, which honours the value without touching state, ClosedDate, iteration, assignee or any other field.

Audit trail

  • Each item got a [Board Hygiene] history note in the same revision as the Effort value — what changed, the rollup it came from, and the bypass.
  • Read-back confirms: #53825 Effort 8 (rev 17), #60421 Effort 57 (rev 12), both still Done, ClosedDate unchanged, iteration unchanged.
  • Reversal is one PATCH per item with the original value blank — the note records it, so nothing depends on this report surviving.

05 Secondary findings worth a human glance

  • 20 child tasks have CompletedWork but no OriginalEstimate. That is why the rollup had to use delivered hours: the estimate side of those tasks is empty, so 8 h and 57 h are actuals, not planned size. If you want Effort to mean "planned size", the tasks need OriginalEstimate first — otherwise this backfill slightly under-states the PBI where a task ran longer than planned.
  • #53825's second child looks mis-parented. Task #59270 — "PO list: add Received (Đã nhận hàng, docStatus 3) status" — hangs under "Dcorp operation" alongside the Dcorp authorization task. It may be legitimate (same vendor feed), but if it is not, then 4 h of that PBI's new Effort belongs to a different PBI. Worth one look; I have not moved it.
  • Sprint 7 is clean but not consistent. All 25 PBIs carry Effort, yet Σ PBI Effort (683 h) sits below Σ completed Task/Defect hours (747 h) — the same "estimate below actuals" pattern, spread thin. Not a backfill job, a planning note for the retro.
